# Learn FreeCodeCamp

This repository is dedicated to storing my learning journey and projects from [FreeCodeCamp.org](https://www.freecodecamp.org/).

## About

FreeCodeCamp is a free, open-source platform for learning web development and earning certifications. This repository serves as a personal collection of my progress, code exercises, projects, and notes from various FreeCodeCamp courses.

## Repository Structure

The repository is organized by FreeCodeCamp certifications and courses:

```
├── Responsive-Web-Design/          # HTML, CSS, Responsive Design
├── JavaScript-Algorithms/          # JavaScript fundamentals and algorithms
├── Front-End-Development/          # React, Redux, front-end libraries
├── Data-Visualization/             # D3.js, data visualization projects
├── Back-End-Development/           # Node.js, Express, databases
├── Quality-Assurance/              # Testing, QA projects
├── Scientific-Computing/           # Python projects
├── Data-Analysis/                  # Data analysis with Python
├── Information-Security/           # Security projects
├── Machine-Learning/               # ML projects with Python
└── README.md                       # This file
```

## Certifications

FreeCodeCamp offers the following certifications (each ~300 hours):

- **Responsive Web Design** - HTML, CSS, Flexbox, Grid
- **JavaScript Algorithms and Data Structures** - ES6, Regular Expressions, Debugging, Data Structures
- **Front End Development Libraries** - React, Redux, Sass, Bootstrap
- **Data Visualization** - D3.js, JSON APIs and AJAX
- **Back End Development and APIs** - Node.js, Express, MongoDB
- **Quality Assurance** - Testing with Chai, functional testing, security
- **Scientific Computing with Python** - Python fundamentals, data structures
- **Data Analysis with Python** - NumPy, Pandas, Matplotlib
- **Information Security** - Security concepts, penetration testing
- **Machine Learning with Python** - TensorFlow, neural networks

## Progress Tracking

Each certification folder contains:
- Practice exercises

## Getting Started

To view or run any project:

2. Follow the README instructions in that folder
3. Check individual project directories for specific setup requirements
