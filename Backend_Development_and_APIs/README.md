# Backend Development and APIs

This directory contains learning materials and projects from FreeCodeCamp's Backend Development and APIs certification.

## Topics Covered

- **Managing Packages with NPM** - Learn how to manage dependencies using Node Package Manager
- **Basic Node and Express** - Introduction to Node.js and Express.js framework
- **MongoDB and Mongoose** - Database management with MongoDB and Mongoose ODM
- **Back End Development and APIs Projects** - Hands-on projects to practice backend skills

## Projects

This section will contain various backend development projects including:
- Timestamp Microservice
- Request Header Parser Microservice
- URL Shortener Microservice
- Exercise Tracker
- File Metadata Microservice

## Getting Started

Each project will have its own directory with:
- Source code
- README with instructions
- Package.json for dependencies
- Tests (where applicable)
